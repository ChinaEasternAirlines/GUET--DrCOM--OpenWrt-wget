# GUET DrCOM OpenWrt wget Auto-Authentication

OpenWrt auto-login script for Guilin University of Electronic Technology (GUET) campus network Dr.COM authentication. Implemented using `wget`, supporting auto-reconnection.
> The following content was generated by DeepSeek or with the participation of DeepSeek 🥰

## Applicable Environment
- OpenWrt 25.12+
- GUET Campus Network Dr.COM Authentication
- "Campus Network" (Mobile/Telecom/Unicom parameters can be modified)

## Installation
> Auto Install

Run the following command in SSH:
```bash
wget -O /tmp/install.sh https://raw.githubusercontent.com/ChinaEasternAirlines/GUET--DrCOM--OpenWrt-wget/main/install.sh
```

If you do not have an external internet connection, please manually download `install.sh` and run it in SSH.

> Manual Install
1. Upload `scripts/wget_auth.sh` to OpenWrt's `/usr/bin/`
2. Grant execute permission: `chmod +x /usr/bin/wget_auth.sh`
3. Modify the student ID, password, and ISP in the script
4. Add a cron job: `crontab -e`, and add:
   `* * * * * /usr/bin/wget_auth.sh > /dev/null 2>&1`

***

## Or operate directly in SSH
### 🚨 Step 1: Complete authentication using wget first

Note:
1. If the password contains symbols like `@`, they must be URL-encoded as `%40`, etc., otherwise it will break the URL structure.
2. Here is an example using Unicom broadband.

```bash
wget -O- "http://10.0.1.5/drcom/login?callback=dr1003&DDDDD=[Student_ID]%40unicom&upass=[Password]&0MKKey=123456&R1=0&R3=2&R6=0&para=00&v6ip=&terminal_type=1&lang=zh-cn"
```

If the returned content contains a success flag like `"result":1` or `dr1003(...)`, the authentication is successful.

### 📜 Step 2: Create auto-authentication script
1. Create a script file in SSH:
```bash
vi /usr/bin/drcom_login.sh
```

2. Enter and save the following content:

```bash
#!/bin/sh
if ! ping -c 1 -W 3 223.5.5.5 > /dev/null 2>&1; then
    wget -O- "http://10.0.1.5/drcom/login?callback=dr1003&DDDDD=[Student_ID]%40unicom&upass=[Password]&0MKKey=123456&R1=0&R3=2&R6=0&para=00&v6ip=&terminal_type=1&lang=zh-cn" > /dev/null 2>&1
fi
```

3. Grant execution permission:
```bash
chmod +x /usr/bin/drcom_login.sh
```

### ⏰ Step 3: Set up cron job for auto-reconnection

Enter the following in SSH:
```bash
crontab -e
```

Add the following line (executes the script every minute to auto-reconnect if disconnected):

```
* * * * * /usr/bin/drcom_login.sh > /dev/null 2>&1
```
